# Jiawei Tong — Personal Academic Homepage

Personal academic homepage for **Jiawei Tong**, Ph.D. Candidate in Information Systems at the University of Melbourne.

- Research focus: AI Accountability, Explainable AI (XAI), Responsible AI Governance, Human–AI Interaction, and Behavioural Information Systems.
- Built as a standalone, lightweight static HTML/CSS/JS site with a Gemini-inspired blue gradient theme, light/dark mode, and full English/Chinese bilingual support.
